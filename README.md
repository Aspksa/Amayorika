# Amayorika

Локальная персональная ИИ-помощница. Версия 0.2.0.

## Запуск Windows

Скачайте репозиторий, установите Node.js LTS и запустите **Amayorika.bat**. Откройте http://127.0.0.1:57474 . Никакой Docker или Python не требуется.

## Подключение

Откройте «Подключение», укажите **полный HTTPS URL** OpenAI-совместимого endpoint для chat completions, название модели и API-ключ. Нажмите «Сохранить», затем «Проверить связь». Конкретный URL Cloud.ru зависит от используемого сервиса и модели.

Ключ сохраняется локально в `data/cloudru-settings.json`, который исключён из Git. Не открывайте локальный порт в интернет и не передавайте файл с ключом. Приложение предназначено для одного пользователя на доверенном компьютере.

## Разработка

`npm.cmd test` — базовые проверки, `npm.cmd start` — сервер, `npm.cmd run dev` — перезапуск при изменениях.

Память, граф знаний и агенты пока являются разделами-заготовками, без обещаний работающего функционала.

## Hermes Agent (отдельный процесс)

Hermes **не включён в репозиторий** и не устанавливается автоматически через BAT. Сначала установите его по [официальной инструкции](https://github.com/NousResearch/hermes-agent). Настройте провайдера командой `hermes model`. Затем включите API-сервер Hermes, задав в его конфигурации:

```env
API_SERVER_ENABLED=true
API_SERVER_HOST=127.0.0.1
API_SERVER_PORT=8642
API_SERVER_KEY=YOUR_OWN_RANDOM_SECRET
```

Запустите `hermes gateway` в отдельном терминале. В Amayorika откройте «Подключение», задайте локальный адрес `http://127.0.0.1:8642`, модель `hermes-agent` и тот же API_SERVER_KEY. Сохраните, проверьте связь, затем выберите «Hermes Agent» над чатом.

Amayorika пересылает запросы к Hermes **только через локальный Node.js сервер**. Браузер не получает секретный ключ. Конфигурация Hermes хранится в исключённом из Git файле `data/hermes-settings.json`. Разрешены только loopback-адреса. Hermes может выполнять команды и работать с файлами с правами запущенного пользователя: ограничьте его инструменты и права, не используйте режим без подтверждений для опасных действий.

Поддерживается обычный ответ OpenAI-compatible chat completions без потокового отображения шагов агента. Визуализация инструментов, управление разрешениями и сессиями потребуют отдельной интеграции с Runs API.

Для работы Hermes потребуется собственное окружение Python; **сам Node.js интерфейс Amayorika Python не требует**.

## Автоматическая установка Hermes при запуске BAT

При первом запуске `Amayorika.bat` загружает официальный установщик Hermes и устанавливает исходники в `.runtime/hermes/hermes-agent`, а данные в `data/hermes`. Повторный запуск пропускает установку при наличии маркера `.runtime/hermes/.installed`. Установка требует интернета и может занять время; браузерные и computer-use зависимости отключены для экономии места. Логи: `logs/launcher.log`. При ошибке установки веб-приложение продолжит запуск, но Hermes будет недоступен до устранения ошибки. Настройка провайдера и запуск Hermes gateway пока выполняются отдельно. Установщик стороннего ПО исполняется локально: изучите `scripts/install-hermes.ps1` перед первым запуском, если требуется контроль поставки.

## Локальная установка MemOS

При запуске `Amayorika.bat` проверяется `.runtime/memos/.installed`. Если MemOS отсутствует, скрипт `scripts/install-memos.ps1` скачивает исходный код из официального [MemTensor/MemOS](https://github.com/MemTensor/MemOS), создаёт изолированное Python-окружение и устанавливает пакет. Для этого профиля нужны **Git и Python 3.11**, доступ в интернет и свободное место. Установщик не требует Docker и не затрагивает системные Python-пакеты.

- Код: `.runtime/memos/MemOS`
- Python-окружение: `.runtime/memos/.venv`
- Постоянные данные: `data/memory/memos`
- Логи ошибок: `logs/launcher.log`

Повторный запуск не переустанавливает MemOS. Данные не удаляются даже при принудительной переустановке. Папки `.runtime/` и `data/` исключены из Git. При сбое MemOS основной Node.js интерфейс продолжает запуск.

**Граница готовности:** это автоматическая установка Python-пакета, а не подключение работающей памяти к чату. Для хранения, поиска и извлечения воспоминаний ещё необходимо выбрать и настроить локальный backend MemOS, адаптер приложения и API Cloud.ru. Совместимость текущей версии MemOS с Python 3.11 и Windows следует подтвердить реальным запуском; версии исходников пока не закреплены.

## Project Golem — 3D-визуализация памяти (подготовка)

Исходный проект: [CyberMagician/Project_Golem](https://github.com/CyberMagician/Project_Golem), лицензия Apache-2.0. При первом запуске BAT исходники клонируются в `.runtime/project-golem/Project_Golem`. Локальные данные Amayorika предполагается хранить в `data/knowledge-graph/golem`. Оригинальные LICENSE и NOTICE остаются в скачанном репозитории. Скачанные исходники не коммитятся в GitHub Amayorika.

**Это только загрузка исходного проекта, не готовая интеграция.** Golem использует Flask, Three.js, LanceDB, UMAP и модель эмбеддингов; оригинальный демонстрационный сценарий скачивает материалы Википедии и создаёт собственный индекс. Он не читает MemOS автоматически. Установка Python-зависимостей, скачивание модели, индексация, запуск сервера и адаптер к локальным данным MemOS требуют отдельного этапа и не выполняются BAT, чтобы не запускать тяжёлую индексацию и не загружать ноутбук неожиданно. Перед включением необходимо проверить требования к Windows, зависимости и формат импорта. Локальное хранение остаётся обязательным.

## Интерактивный граф знаний 0.3.0

Раздел «Граф знаний» отображает локальные узлы и связи из `data/knowledge-graph/graph.json` в интерактивной перспективной 3D-проекции на Canvas. Можно вращать, масштабировать и выбирать узлы. Пустой граф отображается честно, без демонстрационных данных.

**Импорт реальных данных:** подготовьте экспорт MemOS или другого источника в JSON со структурой:

```json
{"nodes":[{"id":"1","label":"Тема","group":"Память","description":"Описание"},{"id":"2","label":"Факт"}],"edges":[{"source":"1","target":"2","label":"связан"}]}
```

Запустите из папки проекта `node scripts/import-graph.mjs путь-к-экспорту.json`. Импорт проверяет идентификаторы и связи, сохраняет данные в локальной папке, затем в интерфейсе нажмите «Обновить данные». Поддерживается до 2000 узлов и 5000 связей за импорт.

**Ограничение:** это работающая визуализация локального JSON-графа, но пока не прямое чтение внутренних хранилищ MemOS и не запуск интерфейса Project Golem. Для автоматической синхронизации нужен адаптер конкретной версии MemOS и его формата экспорта. Трёхмерность реализована математической проекцией на Canvas без GPU-зависимостей.

## Локальная система памяти v0.4 (экспериментально)

Cloud.ru-чат теперь сохраняет ответы в `data/chats/archive.jsonl`, ищет до трёх релевантных предыдущих разговоров и добавляет их в контекст следующего запроса. Из текстов автоматически формируются узлы «Диалоги» и «Темы» в `data/knowledge-graph/graph.json`; они отображаются в существующем графе. Это **простое лексическое извлечение**, а не извлечение фактов MemOS; возможны ложные связи и дубликаты. Ограничение графа — 2000 узлов и 5000 связей. Архив продолжает пополняться даже при достижении лимита графа.

В разделе «Память» отображается количество диалогов и связей. Кнопка «Резервная копия» сохраняет снимок архива и графа в `data/backups/`. Восстановление пока выполняется вручную копированием файлов из снимка при остановленном приложении.

Добавлена локальная API-очередь заданий агентов: `POST /api/agents/task` с JSON `{"type":"analyze","text":"..."}`. Задания записываются в `data/agents/tasks.jsonl`, **но не выполняются автоматически**. Раздел «Агенты» отображает это ограничение.

**Не реализовано в этой версии:** прямое подключение к API MemOS, автоматическая синхронизация MemOS с Project Golem, полноценный 3D-движок Golem, безопасное исполнение агентов, резервирование всех каталогов и автоматическое восстановление. Для Hermes архивирование в данном обновлении не подключено. Проверка на Windows и интеграционные тесты необходимы перед эксплуатацией с важными данными.

## Загрузка шести сторонних проектов

При первом запуске `Amayorika.bat` вызывается `scripts/install-third-party.ps1`. Скрипт клонирует исходники MemOS, Project Golem, Hermes Agent, Mem0, Graphiti и CrewAI в `.runtime/third-party/<имя>`, фиксирует фактические SHA коммитов в `.runtime/third-party-install-status.json`. Данные `data/` не затрагиваются. Для повторной проверки запустите `powershell.exe -NoProfile -ExecutionPolicy Bypass -File scripts/install-third-party.ps1`; с `-Force` выполняется fast-forward обновление исходников. Требуются Git и интернет.

**Установка исходников не означает запуск или интеграцию всех сервисов.** Изоляция Python-зависимостей для Mem0, Graphiti и CrewAI доступна отдельно: `powershell.exe -NoProfile -ExecutionPolicy Bypass -File scripts/install-third-party.ps1 -InstallPython` (Python 3.11). Это экспериментальная установка пакетов в отдельные venv; MemOS и Hermes имеют свои установщики. Project Golem требует дополнительной настройки модели, индекса и сервера. Включение сторонних модулей и ключей делается только после проверки совместимости, лицензий и конфигурации. Docker не используется. Не копируйте токены в GitHub.
